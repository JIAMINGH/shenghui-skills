# 工厂出海核心方法论

## 使用范围
适用于首次出海、获客体系诊断、年度/阶段计划。

## 核心原则
- 主线：海外社媒获取注意力 → B2B 独立站建立信任及承接 → WhatsApp/邮箱外贸聊单 → 商机、报价、订单。AI 用来降低语言和内容成本，不替代客户验证、质量与交付。
- 先判断工厂优势（产品、定制、成本、产能、交付、证书），再定国家、品类、人群。不能把“能生产”当作“有竞争优势”。
- 获客对象优先是进口商、批发商、经销商、品牌方、工程商等符合起订量及服务范围的 B 端，不以粉丝或询盘总数作为唯一成功标准。
- 展会、平台、主动开发与社媒可并行；不宣称某渠道必然胜过所有渠道。
- 先做一个明确目标市场、一个主力产品族、一套可测承接路径；用客户反馈修正产品与内容。

## 执行 SOP
1. 诊断现有渠道、产能、预算、团队与成交链路。
2. 明确目标国家候选、产品定位、客户画像和可证明的卖点。
3. 设计自然流内容、付费小测、独立站页面及聊单分工。
4. 每周复盘曝光、有效询盘率、报价率、商机成本与成交情况；无归因时标注未知。
5. 优先修复漏斗最大损失点，再考虑扩国扩预算。

## 交付标准
输出：现状与约束、目标客户、三段获客路径、30 天动作清单、指标与风险。
