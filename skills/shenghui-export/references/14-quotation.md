# 报价与商业谈判

## 使用范围
适用于成本核算、报价、议价和样品订单。

## 核心原则
- 报价要明确 SKU、规格、MOQ、币种、贸易术语与地点、有效期、交付、付款、包装和质保；Incoterms 按约定版本核实。
- 毛利率 = (销售收入−计入成本)/销售收入；加价率 = (销售收入−计入成本)/计入成本。不得混用。
- 到岸成本需区分货值、运保费、关税、税、港杂、国内/当地费用和各自责任；税基、抵扣、汇率需按目的国核查。
- 不直接把竞争对手零售价除以固定倍数当 FOB 价；用渠道费用、税与利润假设做情景测算。

## 执行 SOP
1. 整理客户目标、实际成本、装箱、MOQ、运输及付款约束。
2. 计算基础报价与可选配置，区分已确认与估算项。
3. 给出数量阶梯、样品与交货方案；让客户理解价格对应价值。
4. 遇压价优先协商配置、数量、包装、付款或交期，不虚构成本或承诺。
5. 涉及合同、信用证、关税与特殊法规时请专业人员复核。

## 交付标准
输出：报价表、费用责任、假设、有效期、下一步；未知数据不得填造。
