# 国家与产品定位

## 使用范围
适用于选择出口国家、主推产品和细分客户。

## 核心原则
- 培训经验中，中东、拉美、英国、澳大利亚、加拿大可以作为候选；美国并非一律排除，需综合认证、成本、竞争、关税及渠道需求判断。
- 先用目标买家需求反推配置和卖点；定制能力、MOQ、交期和一致性应以工厂实际可兑现为准。
- 建议采用可解释的初筛评分：需求 25%、产品适配 25%、利润 20%、渠道可达 15%、合规/收款/物流可控 15%。这是默认示例权重，不是历史实测规律。

## 执行 SOP
1. 梳理产品族、目标出厂价、可定制范围、生产约束及现有出口。
2. 对候选国家逐项打分（1–5），缺证据记未知而不是满分或零分；做权重敏感性检查。
3. 锁定 1–2 个国家、1–2 个产品族、1–2 个买家类型作为首轮测试。
4. 用当地语言搜索、竞品价格、真实询盘以及可比小额广告验证假设。
5. 根据合格线索与毛利空间决定继续、调整或停止。

## 交付标准
输出：国家筛选矩阵、产品-客户匹配表、测试优先级、假设与停止条件。
