# SEO与GEO

## 使用范围
适用于搜索可见性、技术 SEO、多语内容和 AI 搜索可引用性。

## 核心原则
- SEO：可抓取、可索引、符合搜索意图、内容真实且结构清楚。GEO 是面向生成式搜索的内容可理解性与引用友好度实践，不保证排名或被模型引用。
- 区分已提交 sitemap、已抓取、已索引和获得流量；查看 Google Search Console 等实际数据。
- 多语站按真实语言设置 URL、hreflang（如适用）、canonical；不堆砌关键词或批量制造低质页面。
- 结构化数据与页面可见内容一致；不虚构评价、作者、认证。

## 执行 SOP
1. 检查 robots.txt、sitemap、状态码、canonical、索引与性能。
2. 基于当地买家搜索意图做关键词-页面映射，优先产品和采购场景。
3. 编写清晰规格、FAQ、质量与定制说明，引用可靠来源并标注更新时间。
4. 完善标题、描述、内链、图片 alt、适用结构化数据。
5. 用 Search Console 和 PageSpeed Insights 等核查，按实际数据迭代。

## 交付标准
输出：技术问题清单、关键词与页面映射、内容计划、优先级、可验证指标。
