# AI数字人与多语言

## 使用范围
适用于多语文案、配音、混剪、口型同步。

## 核心原则
- 推荐工作流：原始中文文案→目标语本地化→配音→素材混剪→必要时口型同步→审校→发布。
- 先建立可授权的真人素材库；声音或人像克隆需获得授权，必要时按平台规则标注合成内容。
- 不依赖某款工具永久可用。选工具按语种、发音、成本、授权、导出格式和隐私要求；当前功能需查官方文档。
- 不用合成视频虚构客户评价、认证、真实工序或个人身份。

## 执行 SOP
1. 确定语种与地区变体；建立产品术语表和禁止改动参数。
2. 生成目标语口播并回译检查；确认数字、型号、单位。
3. 配音后检查发音、停顿和音量；使用授权声音。
4. 混剪真实素材，若有口型同步检查失真、手势和画面连续性。
5. 核对字幕、CTA、平台披露要求后再发布。

## 交付标准
输出：多语文案、术语表、生产步骤、质量检查、工具候选及验证事项。
