# 平台尺寸与裁切

先区分主页封面、频道头图、广告素材和网站首屏。使用用户已确定的规格或从目标平台帮助页及预览核验。以下为可用的工作起点，项目交付时记录实际尺寸和预览范围。

| 位置 | 工作尺寸或核验方式 | 版面处理 |
|---|---|---|
| Facebook Page 封面 | 可用 **1640 × 624 px** 做设计母版，与技能库广告工具的现有工作尺寸一致。上传要求以 Meta 帮助页和实际主页编辑器为准。 [Meta 帮助中心](https://www.facebook.com/help/125379114252045) | 在桌面和手机预览中对照头像、页名及裁边。把关键产品与文字留在两种预览都看得到的位置，不用同一尺寸直接输出广告版位。 |
| LinkedIn 企业主页封面 | 官方企业页说明列 **1512 × 256 px**。 [LinkedIn 企业主页图像规格](https://www.linkedin.com/help/linkedin/answer/a563309/image-specifications-for-your-linkedin-pages-and-career-pages) | 横幅高度较窄，主要元素居中，边缘留作背景延伸。 |
| YouTube 频道横幅 | 官方建议 **2560 × 1440 px**。在 **2048 × 1152 px** 最低上传尺寸下，文字与 Logo 的安全区为 **1235 × 338 px**。 [YouTube 频道品牌说明](https://support.google.com/youtube/answer/10456525) | 将文字、Logo 及关键主体放进预览中的共用安全区，向四周延伸场景给更大的屏幕。 |
| 独立站 Banner | 采用实际组件比例、断点与文字区域。有样式或页面截图时据此确定，暂无页面时先给可调整的工作尺寸。 | 同时预览桌面和最窄移动视口。文案由网页排版时，图片为文字留出低干扰区域。需要不同构图时单独交付移动版。 |

用目标版位做裁切预览，核对主体、Logo、整行短标语均在可视区域。需要改变比例时裁切留白或扩展背景，保持真实产品与 Logo 原比例。实际平台预览不可用时，标明本次仅做了裁切模拟。
