# 内置视觉方向

用户没有参考图或指定风格时，依据现有品牌资产和画面要完成的事选择一个方向。

| 方向 | 适用素材 | 构图与处理 |
|---|---|---|
| 工厂现场 | 能公开的真实生产线、车间或展厅 | 让工序或产品成为一眼可辨的主体。用景深、色调和干净留白建立层次，保留现场真实环境。 |
| 产品主视觉 | 一张清楚的主推产品图或一组能匹配的同系列实拍 | 优先让结构和用途看清。保留产品原图和合适的接地阴影，用简单背景衬托材料和轮廓。 |
| 应用场景 | 可说明型号用途的实拍，或获准使用的场景素材 | 用环境交代产品解决的采购需求。实际产品与概念场景分开取材，避免让观众误认未经证实的产能、工况或性能。 |

从官方 Logo 或已有品牌视觉取主色，背景用能形成清楚对比的中性色。产品有多色或材质时，控制周围的色彩干扰。首页有独立标题区时，横幅可只交付视觉画面，文字交给页面展示。
