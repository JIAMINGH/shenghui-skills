# 参考图风格提炼

## 看什么

在视觉工具中打开实际图像。记录看过的图和无法打开的图，用文件名或用户提供的链接定位。多张图对照时，优先找反复出现且适合本次品牌的规律。

| 观察维度 | 记录要点 |
|---|---|
| 构图 | 主体位置和占比、视线顺序、文字留白、背景层次 |
| 色彩与光线 | 背景明暗、主色与强调色的比例、光线方向、阴影与反光 |
| 产品呈现 | 镜头角度、比例、产品表面材质、工厂场景与产品的关系 |
| 文字与品牌 | 字数、对比度和层级，Logo 大小及位置，仅借鉴布局原则 |
| 跨平台可用性 | 哪些留白可裁，哪些内容必须留在安全区 |

每条结论写上能复查的对应图。单张图提供的是该图做法，多张证据一致时再归纳为风格规律。只在实际内容足够时记录具体色值、字体或镜头角度，否则用可观察的描述。

## 风格档案结构

按需填入用户项目的 `style-profile.md`。几张图只支持部分结论时，保留相应范围。

1. 参考来源、此次查看范围、适用行业和平台。
2. 观察到的构图、色板、光线、留白和排版。
3. 可迁移的设计规则及如何用目标品牌实拍实现。
4. 针对本项目调整的地方，以及被裁切或复制造成的风险。
5. 一段可复用的风格描述，保留变量给目标品牌、产品和平台。

已有档案只沿用仍与本次目标匹配的规则。参考品牌的标语、Logo、独特装饰和产品结构留在来源图中。
