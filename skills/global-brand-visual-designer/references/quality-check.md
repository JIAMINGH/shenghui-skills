# 封面交付验收

用最终导出的图片检查，可以的话同时查看桌面、手机和相应平台的实际预览。

1. **画面信息。** 目标买家能一眼看懂工厂提供的产品或服务。背景、用语和产品识别度符合该企业与目标市场。
2. **品牌与事实。** 公司名、产品型号、语言和 Logo 与已确认素材一致。认证、产能及年限有可复核来源。参考图仅提供风格规律。
3. **真实产品。** 放大与原图比对轮廓、配件、颜色和标识，检查拼接边缘、阴影和反射。
4. **版面适配。** 按实际像素和裁切预览检查文字笔画清楚、主体完整、头像等界面元素没有挡住关键内容。
5. **可交付性。** 确认文件可打开，实际尺寸、格式和命名正确。建议另存不同平台版本以便复用。

先修复影响使用的缺陷。交付时给一张成图及其像素与用途，简述有影响的素材缺口或预览限制。纯风格分析交付观察与复用规则，按用户要求保存风格档案。
